# Stripe-inspired Visual Reference — Shkolla e Mesme e Mjekësisë

This is a **visual refinement reference only**. It is not a brand migration.

## Hard rules

- Keep the portal's current light and dark colors exactly as defined in `app/globals.css`.
- Keep all educational and UI content unchanged unless a separate content task explicitly requests edits.
- Do not add the word Stripe, Stripe logos, Stripe assets, Stripe colors, Stripe gradients, or Stripe product patterns to the user-facing product.
- Preserve medical-school identity and current navigation/learning behavior.

## Borrow only these qualities

### Professional SaaS polish
- deliberate hierarchy;
- consistent spacing;
- quiet surfaces;
- crisp typography;
- strong alignment;
- obvious primary actions.

### Whitespace
- generous between major sections;
- tight inside related groups;
- avoid both cramped layouts and oversized empty zones.

### Compact cards
- less ornamental padding on analytics cards;
- labels smaller than values;
- consistent radii;
- subtle token-based border/shadow;
- no unnecessary nested cards.

### Tables and forms
- strong label-to-value alignment;
- compact but readable row rhythm;
- restrained borders;
- clear focus/error/disabled states;
- consistent control height.

### Information hierarchy
- one dominant message per section;
- secondary metadata quieter than primary data;
- primary CTA obvious without making every action primary;
- dashboards prioritize decisions over decoration.

### Motion
- short and functional;
- no animation added only to make the UI feel "fancier";
- honor reduced-motion preferences.

The test: the result should feel more precise and premium while still unmistakably being the same Shkolla e Mesme e Mjekësisë product.
